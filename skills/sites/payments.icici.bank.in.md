- ICICI Bank's net banking sign-in, opened by iShop's "Proceed to Login". Type [profile:icici_user_id] into "USER ID"; type [ask] into "PASSWORD" (the system asks the user for it in the hidden field). Leave "Use Virtual Keyboard" unticked and press SECURE LOGIN.
- A code sent by SMS: type [ask] into its box. ICICI then brings the user back to iShop.
- Never press "Forgot your User ID?" or "Forgot your password?". If the page says the User ID or password is wrong, STOP and say so: a second wrong try may lock the account.
