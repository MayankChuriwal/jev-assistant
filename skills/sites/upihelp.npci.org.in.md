- NPCI's MyUPI portal lists every UPI AutoPay mandate (subscriptions paid by UPI: Netflix, Spotify, YouTube Premium, …) across all the user's UPI apps, and can revoke one.
- Sign-in, in this order: type the user's phone ([profile:phone]) into the mobile number box ("Eg. 9876543210"); the captcha beside "Security Verification" goes to the user as a picture, and the text they read goes into that box; tick the "I have read and agree" checkbox; press Continue. The code sent by SMS then goes in through the hidden field.
- A wrong captcha or an expired code shows an error: press Refresh CAPTCHA (or resend the code) and ask again; never guess.
- After sign-in, open Mandate Management. Each mandate shows its merchant, amount and frequency; find the one whose merchant the goal names.
- Revoking that mandate is the final step and needs the user's yes. A pause is not a cancellation.
- When no mandate for that merchant is listed: DONE saying no UPI AutoPay mandate for it was found, quoting the merchants that are listed.
- Report what was revoked (merchant, amount, frequency, any reference shown) and that future UPI payments to it stop; the merchant's own account isn't closed by this.
