---
name: lookup
description: Find, check, or compare information on the web: prices, timings, policies, ratings, availability; also comparing prices across grocery or shopping apps where nothing is bought
inputs:
report: the answer, where it came from
---
## Plan
1. Go where the answer is: the site the user named, else a Google search (https://www.google.com/search?q= with the words).
2. Open the most relevant result and read the answer on the page.
3. To compare: find the same item on each site, note each price, then compare.
4. DONE with the answer, restating what was asked, and quote the page.
## Rules
- Searching and reading public information never needs a sign-in: close sign-in pop-ups instead.
- "The cheapest" or "the best" needs every candidate checked, not only the first one.
- Say when an answer comes from a search result snippet rather than the source site.
- A place the goal names (an area or neighbourhood) is set first with the site's location control, never typed into the dish or product search or a filter box.
- "Best-rated", "cheapest", or "closest" means sorting by that, never a cut-off number the user didn't give.
- A filter that leaves nothing: loosen it one step before reporting that none was found.
- Comparing across sites: when one site can't serve the item or place, say which, and still finish the others before DONE.
